# ADR-0002：唱歌选用 SoulX-Singer 与规则旋律

> **已被 [ADR-0017](0017-singing-all-yue2-rvc.md) 取代（2026-11-10）。** 旧 SoulX 链路
> 已从主仓删除；本文只保留当时的决策背景与评测记录，不再描述产线。

## 背景

需求是“让她自己唱”，而不是翻唱别人的歌。可选路线：SVC 翻唱、TTS + WORLD 重设基频、SVS 直接合成、LLM 直接写音符。

## 决策

1. **SVS（SoulX-Singer，score 模式）**作为合成引擎，参考音与生产 TTS 同一条。
2. **旋律不用 LLM 写音符**，用规则生成：童谣动机库 + 句级语义姿态 + 字级时值 + 中文声调约束。
3. **后期 +2 半音**，手法与生产 TTS 一致（重采样 + 时长还原），不用 WORLD 搬共振峰。
4. 伴奏用拨弦琶音 + 轻低音（0.045 / 0.035）。

## 备选与放弃理由

| 方案 | 放弃原因 |
|---|---|
| Seed-VC / SVC 翻唱 | 音色不对；已删 3.5GB |
| TTS + WORLD 重设基频（研发期脚本） | 电音重；用户明确否决 |
| `childify.py`（WORLD 童声） | 电音来源，保留作反面教材 |
| LLM 直接生成音符 | 不可控、声调错误多；改为规则 + 语义姿态 |
| 旋律飞轮自动调参 | 5 轮不收敛，判据错配 |
| `fits_words` LLM 语义评分 | 对照实验失败，弃用 |

## 后果

**正面**：音色一致；旋律可解释、可复现；11–13s 短歌可离线生成。

**负面**：

- 旋律与词义只到句级，细节适配弱。
- 第 4 句收句动机窄（4 度）。
- SVS 输出非确定，无法用音频哈希做回归。
- 尚未接入产品，显存需与 TTS 串行。
