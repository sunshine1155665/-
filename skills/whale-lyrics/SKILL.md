# 鲸鱼娘作词规则

核心：**先有话，再有句，最后才是字数。** 不要先摆四个九字格再往里塞字；那样一定出现“语义跳、语气词堆、句句一个调”。

## 0. 先判断任务

- **写新词**：从场景/情绪/对象开始，走 Stage 1–4。
- **改旧词**：先跑 lint，再判断是“结构错”还是“字句错”；结构错回 Stage 1，不要只抠字。
- **已有旋律要填词**：先数每句音符/重音拍，音节预算=该句音符数；字调检查放到 Stage 3。
- **只要 36 字管线版**：先自由写，最后做 Stage 5 的 `pipeline_36` 适配；不要为了 36 字牺牲语义。

## 1. 四阶段

### Stage 1：Beat sheet（不写词）

产出一页 `LYR-SPEC.yaml`：

- `brief`：一句话说清“这首歌在干什么”（安慰/邀功/撒娇/道歉/邀请）。
- `addressee`：对谁说；此刻关系状态。
- `anchor`：一个能看见的具体物/身体部位（杯子、外套、尾巴、雨伞）。
- `beats`：3–6 句，每句一个功能：观察 → 动作 → 邀请/转折 → 情绪落点。
- `length_curve`：设计句长，如 `8-7-6-10`；允许 3–6 句、5–11 字/句。
- `stress_beats`：每句 2–4 个重音拍（实词），配对句重音位置一致。
- `rhyme`：默认 ABCB（2/4 押）；第 3 句可故意不押。
- `tone_notes`：每句最高音/长音准备落在哪个开口音。

**通过条件**：一句话能复述；锚点最迟第 2 句出现；第 4 句回到锚点或“他”；长度曲线至少一处变化。

### Stage 2：Draft（按骨架写，不按字数凑）

每写一句，做三件事：

1. **接旧信息**：句首用代词/零主语/重复名词/对比，接住上一句。
2. **只加一个新信息**：不要一句里塞两个新东西。
3. **一口气念得完**：按 2–4 字意群切，不要 4 字以上不断。

不要为了押韵倒词序；不要生造词；不要四句都用“呀/啦/吧”收尾。

### Stage 3：Lint + 念读

```bash
python skills/whale-lyrics/scripts/lyrics_lint.py lyrics.txt --json
```

硬失败优先；同一个硬失败改两遍还在，回 Stage 1 改结构，不要继续抠字。
再让一个没看过词的人听你念一遍，让他复述；复述错就是谐音/语流有问题。

### Stage 4：Singability rewrite（对着旋律唱）

改动代价从低到高：

1. 换同调同义词；
2. 调词序；
3. 加/删非重读语气词；
4. 给字加时值/拖腔；
5. 改第 3 句长度；
6. 最后才改旋律。

每句最高音/拖长音优先开口韵（a/ang/ai/ao）；句末音至少 1.25× 平均时值，末句 1.5×。

## 2. 硬门禁（机器可查）

只拦真正影响可用性的：

- **结构**：3–6 句；每句 5–11 个汉字；4×9 允许，不强制改。
- **重复**：不把上一句原样复读。
- **连贯**：相邻句至少有内容词重叠/代词/零主语链接；完全没有链接才硬失败。

其余是**强建议**（lint 警告，人耳裁决）：

- 连续 3 句同字数 → 提醒长度曲线太平，但允许 4×9；
- 每句语气词 ≤1、全歌 ≤2；语气词不做韵脚；
- 2/4 句同辙；不重复同一个韵脚字；不用虚词押韵；
- 最后一句尽量不引入新名词。

## 3. 软规则（lint 警告，人耳裁决）

- 每句重音拍 2–4 个；配对句重音位置一致，音节差 0–2。
- 句末焦点落在最后一个实词；不以“的/了/着/吗/呢/吧/啊/嘛”收句（问句除外）。
- 连续 3 字同声母/同韵母：换字。
- 连续同调 ≥4 警告；连续一声 ≥4 硬失败（当前旋律生成器最怕）。
- 每句最高音/长音给开口音；闭口音（i/u/ü/ei）只放短音或气声。
- 全歌“主人哥哥” ≤1 次，自称 ≤1 次；至少一次“壳硬底软”；至少一个身体标点（尾巴/鳍/耳朵）。
- 抽象名词 ≤1 个；成语链 ≤1；不要“啦啦啦”、emoji、舞台指示。

## 4. 输出契约

```text
LYR-SPEC.yaml     # 意图、锚点、四拍、长度曲线、重音、韵脚、风险
lyrics.txt        # 自由句长版本（3–6 句）
pipeline_36.txt   # 可选：当前 36 字管线适配版
lint_report.json  # lint 结果
```

`pipeline_36.txt` 只做“适配”，不改语义：

- 优先删非重读语气词/修饰语；
- 其次合并同义短语；
- 最后才加衬字；
- 在 `LYR-SPEC.yaml` 的 `adaptation` 里记录删/加了什么、为什么。

当前 `general_song_original.py` 仍要求 36 字；这是管线限制，不是作词规则。以后应支持按句音符数直接映射，不再强制 36。

## 5. 反模式（本项目真实踩过）

- 四句都“呀”：语气词预算爆，唱起来像念经。
- “开心/温暖/幸福”当名词：没有画面，pro 会判空。
- 第 2 句另起一个场景：话题链断，听感“语义跳”。
- 句尾重复同一个字（“抱我我我”）：不是歌词问题，是加花映射问题；歌词层要避免连续同字收尾。
- 为了押韵写“抱紧紧抄”：倒词序/生造词，唱出来会误听。
- 每句都九字：长度曲线平，旋律容易平；允许 `8-7-6-10`。
