# 字调与旋律：倒字、长音、开口音

## 1. 裁决顺序

**字调 > 句调 > 重音。** 先保证字不被唱倒，再谈句子起伏和强调。

## 2. 倒字风险

倒字不是“音高变了”，而是“进入这个字的音程方向和字调型冲突”。

| 字调 | 调型 | 忌讳的进入方式 |
|---|---|---|
| 阴平（1 声，55） | 高平 | 从低处向上大跳进入 |
| 阳平（2 声，35） | 中升 | 从高处下行进入 |
| 上声（3 声，21/214） | 低降/降升 | 从低处上行进入 |
| 去声（4 声，51） | 全降 | 从低处上行进入 |
| 轻声 | 短弱 | 权重减半，不硬判 |

只查三类位置，不要全曲逐字判：

1. 每句最高音；
2. 句首字；
3. ≥5 半音大跳的落点。

## 3. 大跳规则

- ≥3 半音跳进，落点优先二声/四声，或放在句首/句尾。
- 一声、三声、语气词上不要放大跳。
- 连续 4 个以上同调：警告；连续 4 个以上一声：硬失败（当前旋律生成器最怕，容易把旋律逼成 7/9 来回摆）。
- 三声连读 ≥3：只警告，普通话常见。

避不开时：

1. 换同义不同调字；
2. 改时值/拖腔；
3. 最后才改音高走向。

## 4. 长音与开口音

- 每句最高音、拖长音优先开口韵：a/ang/ai/ao。
- 闭口音（i/u/ü/ei）只放短音或气声收尾。
- 句末音 ≥1.25× 平均时值；末句 ≥1.5×。
- 重音与字调冲突时，改时值/力度，不改音高走向。

## 5. 先词后曲 / 先曲后词

- **先词后曲**：Stage 3 只做“高风险位置”预警；旋律出现后再复检。
- **先曲后词**：音节预算 = 该句音符数；先保重音拍，再填非重读字。
- 当前 `notes_to_target` 是一字一音；多出来的音会在句末做加花。作词时句末尽量留一个可拖长的开口音实词。

## 6. g2pM 的边界

- 不做变调：`一起` 可能标 yi1 qi3；用词汇调或人工复核。
- 轻声/儿化不稳：`尾巴`、`得`、`女儿` 不要用轻声做硬失败。
- `ü` 常写作 `u:`；多音字可能选错，标“需人审”。
- 声调检查只输出 risk，不做最终判决。
