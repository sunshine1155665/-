# 语义连贯：话题链与已知-新信息

## 1. 一句话意图

先写一句“这首歌在干什么”：

> 她下班回家，看到主人淋雨，嘴上嫌他，手上给他擦头发。

如果这句话写不出，四句一定散。四句只服务一个言语行为：安慰、邀功、撒娇、道歉、邀请。

## 2. 一个锚点 + 一次转身

- 选一个能拍到的具体物/身体部位：杯子、外套、雨伞、尾巴、耳朵。
- 最迟第 2 句出现。
- 第 4 句以“变化后的样子”回来：外套从湿到被挂起，杯子从空到被续上，尾巴从藏到摇。
- 抽象词只做谓语，不做主语；全歌抽象名词 ≤1。

检查：把形容词全划掉，还剩不剩一个能看见的东西？

## 3. 已知-新信息链

中文歌词常省略主语，零主语不是病句；关键是“接得住”。

- 第 2–4 句句首先接旧信息：代词（你/它）、零主语、重复名词、对比（“不是 A，是 B”）。
- 每句只加一个新信息。
- 话题转换最多 2 次；每次转换必须用名词点明。
- 第 4 句不引入新名词（除非 `deliberate_turn` 写明理由）。

例：

```
雨点敲在窗玻璃上        （新：雨）
我把热汤盛进碗里        （接“我”；新：汤）
你今天回来得有点晚      （接“你”；新：晚）
先喝一口再说话          （接“汤/喝”；落点：他）
```

## 4. 四拍功能

默认 4 句，但允许 3–6 句：

| 拍 | 功能 | 不要 |
|---|---|---|
| 1 观察 | 一个具体画面/触发 | 不要先讲道理 |
| 2 动作 | 她做了什么 | 不要另起场景 |
| 3 转折/邀请 | 嘴硬、撒娇、提问 | 不要引入第三个新名词 |
| 4 落点 | 回到他/锚点 | 不要新画面、新人物 |

3 句版：观察 → 动作 → 落点。  
5–6 句版：把“动作”拆成两步，但每句仍只加一个新信息。

## 5. 一句话复述测试

写完让没看过词的人听你念一遍，然后让他用“因为……所以/但是……”复述。

- 复述得出：连贯。
- 只会说“很可爱/很甜”：画面不够。
- 复述成另一件事：话题链断了。

## 6. 常见断链

- 第 2 句突然换地点/时间，没有过渡。
- 第 3 句引入新人物/新物件，第 4 句接不回来。
- 四句都是并列画面，没有“动作—反应”。
- 句尾全是语气词，信息量被语气吃掉。
