# 语句流畅：意群、重音拍、句长、押韵

## 1. 先切意群，再写字数

每句切成 2–4 个意群：

- 2+2+3：`雨点 / 敲在 / 窗玻璃`
- 2+3：`我把 / 热汤盛进碗里`
- 3+2：`先喝一口 / 再说话`
- 2+2+2：`天亮了 / 窗帘 / 慢慢拉开`

不要 4 字以上不断；一口气念不完就拆。1 字意群只留句末语气词或刻意顿挫。

## 2. 重音拍固定，音节数浮动

- 每句先标 2–4 个重音拍（实词，不标虚词）。
- 配对句（1/2、3/4）重音位置尽量一致。
- 音节增减只发生在重音拍之间；用语气词、衬字、修饰语填充。
- 句长 5–11 字；禁止连续 3 句同字数。
- 默认第 4 句略长，但不强制；长度曲线至少一处变化（如 8-7-6-10）。

这样字数变了，唱起来的骨架没变。

## 3. 句末焦点与语气词预算

- 一句一个主要重音，落在句末最后一个实词。
- 不以“的/了/着/吗/呢/吧/啊/嘛”收句（整句问句除外）。
- 每句语气词 ≤1；全歌 ≤2。
- 语气词算音节，不能当韵脚。

反例：

```
今天也要一起加油呀
早安呀我的主人哥哥
```

两个“呀”+“哥哥”，语气词和信息挤在一起，唱起来会平。

## 4. 押韵：先定辙，再写词

- 默认 ABCB：第 2、4 句押；第 3 句可故意不押做“转”。
- 从标题/关键词的韵脚选辙；不要先写四句再硬凑。
- 韵脚用实词、开口音（a/ang/ai/ao 优先），因为句末常拖长。
- 闭口音（i/u/ü/ei）只放短音或气声收尾。
- 不重复同一个韵脚字；不用虚词/轻声押韵；不为押韵倒词序。

常用十三辙（普通话）：

| 辙 | 主要韵母 | 例 |
|---|---|---|
| 发花 | a/ia/ua | 花、家、啦 |
| 梭波 | o/e/uo | 河、歌、我 |
| 乜斜 | ie/üe | 夜、月 |
| 姑苏 | u | 书、湖 |
| 一七 | i/ü | 你、雨 |
| 怀来 | ai/uai | 来、快 |
| 灰堆 | ei/ui | 谁、回 |
| 遥条 | ao/iao | 好、笑 |
| 由求 | ou/iu | 走、秋 |
| 言前 | an/ian/uan/üan | 晚、圆 |
| 人辰 | en/in/un/ün | 门、心 |
| 江阳 | ang/iang/uang | 光、想 |
| 中东 | eng/ing/ong/iong | 风、梦 |

## 5. 口语可念、不绕口

- 不为押韵倒词序、不生造词。
- 连续 3 字同声母（z/c/s、zh/ch/sh、j/q/x 最危险）或同韵母：换字。
- 念给没看过词的人听，让对方复述；复述错就是谐音误听。
- 避免“抱紧紧抄”这类为了押韵硬造的搭配。

## 6. 长度曲线示例

```
8-7-6-10   观察 8 / 动作 7 / 转折 6 / 落点 10
7-8-6-9    短-长-短-收
6-7-7-10   前紧后松
```

不要四句全 9；也不要把“不对称”全砸在第一句。第 3 句可以最短，第 4 句收束。
